如何用 F12 破解這個密碼系統？

這個教學示範的是「自己檢查網頁原始碼」的解謎方法。它適合拿來學習 HTML、JavaScript、DevTools 與簡單的編碼/雜湊概念。

注意：這套系統是故意設計成「可以被玩家從原始碼破解」的遊戲。真正的網站密碼不應該把驗證資訊放在前端。

01｜開啟 F12

打開 auth.html，按：

F12 或 Ctrl + Shift + I

切到 Elements，不要只看網頁畫面。

02｜找到第一個標記 CASE-19

在 Elements 裡按 Ctrl + F，搜尋：

CASE-19

你會找到一個故意隱藏的區塊。即使它有 hidden，它仍然存在於 HTML 原始碼裡。

<div hidden aria-hidden="true" data-trace="CASE-19"> <!-- CASE-19: 第一個標記只負責帶路。下一站搜尋 NODE-4。 --> ...

重點不是猜密碼，而是讀出下一個搜尋標記：NODE-4。

03｜從 Elements 追到 JavaScript

找到第一個標記後，依照它留下的下一個搜尋標記繼續追蹤。進入 Sources 後，搜尋下一個節點。

搜尋標記 → 下一個標記 → JavaScript 資料

你會看到幾組數字陣列。這些資料是解謎用的中間片段，不要只看變數名稱，要確認它們實際代表什麼。

04｜判斷資料的編碼方式

如果看到一串像 50 48 50 ... 的整數，可以先檢查它們是否落在常見 ASCII 字元範圍。

數字陣列 ↓ 逐個轉成字元 ↓ 得到一個文字片段

不要把教學頁當成答案表；真正的數值應該從你正在破解的 auth.html 裡自己找到。

05｜最重要：追蹤組合順序

找到幾個片段後，繼續搜尋程式碼中負責組合它們的變數或運算。

片段 A 片段 B 片段 C ↓ JavaScript 的 + / template string / function ↓ 最終字串

重點是看實際運算順序，而不是猜測哪個片段應該放前面。

06｜回到密碼頁驗證

當你從 auth.html 的 F12 / Sources 完成推導後，回到登入頁，把自己得到的完整字串輸入密碼欄。

這個教學頁刻意不保存實際線索數值、文字片段或最終密碼。答案只應該從目標網頁的原始碼中推導出來。
